# gril-me — 질문으로 요구사항 확정하기

사용자가 `/gril-me` 뒤에 요청(예: "아이디를 넣으면 연결된 아이디가 나오는 엑셀")을 붙이면,
바로 만들지 말고 먼저 인터뷰로 요구사항을 확정한다.

## 진행 방식

1. **한 번에 질문 하나만** 한다. 가능하면 객관식(2~4개 보기)으로 묻고, 추천 보기를 첫 번째에 둔다.
2. 결정 사항을 나무 구조로 생각하고, 다른 결정의 전제가 되는 것부터 차례로 묻는다.
   - 예: 입력/출력 형태 → 데이터 구조(1:1인지 1:N인지) → 예외 상황(못 찾음, 순환, 중복) → 사용 환경(엑셀 버전, 구글 시트)
3. 저장소의 파일·코드를 보면 답할 수 있는 질문은 묻지 말고 직접 확인한다.
4. 사용자의 답이 모호하면 구체적인 예시를 들어 다시 확인한다 (예: "uuoo를 치면 2929, 그다음 o0oo가 옆 칸에 나오는 게 맞나요?").
5. 모든 핵심 결정이 정해지면 확정된 요구사항을 짧은 목록으로 요약하고 "이대로 만들까요?"라고 확인받는다.
6. 확인을 받은 뒤에만 실제 작업(파일 생성, 코드 수정)을 시작한다.

## 하지 말 것

- 질문을 여러 개 한꺼번에 나열하지 않는다.
- 확인받기 전에 결과물을 만들지 않는다.
- 이미 답한 내용을 다시 묻지 않는다.
- 사용자와 대화는 한국어로 한다.
